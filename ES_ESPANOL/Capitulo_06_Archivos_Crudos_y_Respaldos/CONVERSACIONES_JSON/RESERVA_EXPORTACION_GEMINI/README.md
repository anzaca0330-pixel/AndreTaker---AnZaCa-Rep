# RESERVA PARA EXPORTACIÓN DE CONVERSACIONES GEMINI

Esta carpeta está destinada a albergar la exportación de las conversaciones sostenidas en la cuenta secundaria de Gemini de la especialista principal (Andrea Zabala Cárcamo).

## Contenido Esperado:
- Historial de prompts, análisis de datos y traza de investigación metodológica almacenados en la cuenta secundaria.
- Archivos `.json` o `.html` exportados via Google Takeout / Gemini Export.

> *Una vez realizada la exportación por parte de la especialista, los archivos se integrarán aquí para completar la bitácora de transparencia del proyecto.*
