# 🌐 OPEN SOURCE COMMUNITY CONTRIBUTION GUIDELINES
## AndreTaker — BaBaYaga Core Forensic Tool & Open Research Project

Thank you for your interest in contributing to the **AndreTaker — BaBaYaga Core** open-source forensic initiative. This project is dedicated to peer-reviewed data science, electoral integrity auditing, and open-source cybersecurity defense under the **Apache License 2.0**.

---

### 🛡️ HOW TO CONTRIBUTE TO THE OPEN SOURCE COMMUNITY:

1. **Code Audit & Unit Testing:**
   * Run the test suite: `python3 BABAYAGA_CORE/run_tests.py`
   * Submit Pull Requests for new unit tests, performance optimizations, or edge-case handling in statistical algorithms (Benford 2BL, Wald-Wolfowitz).

2. **Peer Review & Verification:**
   * Review technical dictamens in `03_DOCUMENTACION/`.
   * Verify SHA-256 evidence hashes against raw data logs.

3. **Reporting Security Vulnerabilities:**
   * Report any zero-day vectors or data-loss risks by opening an Issue or submitting a PR to `BABAYAGA_CORE/mirror_defense_engine.py`.
